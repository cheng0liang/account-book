# 002 用户、登录与家庭

## 目标
1. 应用需要登录；新增用户模块（ab-user）。
2. 用户资料：用户 id、昵称、手机号、性别、住址、出生日期、国家。
3. 登录时尽力获取经纬度并记录到「用户定位关联表」，含定位时间；定位失败不阻断登录。
4. 「账户授权登录关联表」记录各平台授权信息。
5. 登录方式：手机号、Apple、Google、微信、QQ、LINE。
6. 家庭系统：创建/加入家庭；成员可查看整个家庭成员的消费，并以家庭为维度做消费统计。

## 用户故事
- 手机号 + 短信验证码登录，首次登录自动注册。登录页默认手机号 + 国家区号：默认中国 +86，仅当定位识别到其他国家且用户未手动选择时才切换；验证码输入框默认为空。
- 对接短信网关前使用固定验证码（`ab.auth.sms.fixed-code`，默认 `000000`，仅临时）。
- 第三方授权登录；同一账号可在「我的」中绑定多个平台，已被其他用户绑定则拒绝。
- 登录时请求定位；失败/拒绝则跳过（默认 `ab.auth.require-location=false`），设为 true 才阻止登录。
- 「我的」页：查看/修改资料，绑定第三方账号，查看最近登录位置，退出登录，注销账号。
- 注销账号：永久删除用户、会话、定位、第三方绑定及其全部小票与图片，同一手机号之后可重新注册；仍有其他成员的家庭创建者需先移除成员（409）。
- 创建家庭 → 得到 8 位邀请码；他人输入邀请码加入；一人至多一个家庭。
- 首页/列表/图表可切换「我的 / 家庭」。家庭范围可读全部成员小票，但只能修改自己的。

## 非目标 / 已知限制
- 真实 Apple/Google/微信/QQ/LINE 授权与真实短信网关需要各自凭据，未在本地联调；仅验证了 dev-mode 的 mock 流程。
- 不存第三方 access/refresh token。
- 不做多家庭、角色细分（仅 OWNER/MEMBER）、转让所有者。

## 验收
- 未登录访问 `/api/**` 返回 401；登录后正常。
- 家庭范围合计 = 成员个人合计之和；非成员访问他人小票 404；非本人修改/删除 403。
- 退出/被移出家庭后立即不再共享。
